# Weld Diagnosis — reading your bead (manual pp.34–40)

Examine the weld after it cools and slag is removed; adjust technique from what you see. [p.34]

## Strike test (p.34)
Weld two scraps, cool, clamp one in a vise, strike the other with a dead-blow hammer (wear ANSI goggles, stand clear underneath). **Good weld bends and is not brittle; poor weld snaps or cracks at the weld.** The test destroys the weld — technique indicator only.

## Heat / penetration scale — wire welds (pp.35–36)
Profiles: **Inadequate penetration** (not hot enough — weld sits on the surface, doesn't fill the joint) ↔ **Proper penetration** (weld visible underneath and bulges slightly on top) ↔ **Excess penetration / burn-through** (too hot — weld droops through or makes a hole).
- To **increase** heat/penetration (thicker work): a. increase weld current · b. decrease travel speed · c. faster wire feed · d. shorter CTWD.
- To **reduce** heat/penetration (thinner work): e. decrease weld current · f. increase travel speed · g. slower wire feed · h. longer CTWD.

## Wire-weld defect patterns (p.35 examples + pp.36–37 causes)
| Symptom | Causes → fixes |
|---|---|
| **Voltage too low / wire feed too slow** (tall ropey bead) | Increase output voltage or increase WFS |
| **Voltage too high / wire feed too fast** (flat, erratic) | Decrease output voltage or decrease WFS |
| **Travel speed too fast** (thin stringy bead) | Travel slower |
| **Travel speed too slow** (wide heavy bead) | Travel faster |
| **CTWD too long or wrong polarity** (spattery, ropey) | Check polarity; keep CTWD < 1/2" |
| **Excess penetration / burn-through** (p.36) | Workpiece overheating → reduce WFS / current; travel speed too slow → speed up and keep steady; excessive material → reduce WFS |
| **Inadequate penetration** (p.36) | Keep ≤1/2" CTWD, arc on the leading edge of the puddle, proper gun angles; reduce travel speed / increase current; bevel thick pieces, allow slight gap, multiple passes; increase WFS |
| **Bend at joint** (p.36) | Clamp properly / tack weld; excessive heat → weld small portions, cool, increase travel speed, reduce WFS |
| **Weld not adhering** (p.36) | Stringer bead placement, correct angles, pause at weave sides, arc on leading edge; increase current + WFS; clean to bare metal; widen groove/bevel |
| **Porosity — small cavities/holes** (p.37) | **1. Incorrect polarity** · 2. insufficient shielding gas (MIG only: raise flow, clean nozzle, proper CTWD) · 3. wrong gas (use wire supplier's recommendation) · 4. dirty workpiece or wire (clean to bare metal; wire free of oil/coatings) · 5. inconsistent travel speed · 6. CTWD too long |
| **Excessive spatter** (fine spatter is normal; grainy/large is not) (p.37) | Dirty workpiece/wire · incorrect polarity · insufficient gas (MIG) · wire feeding too fast · CTWD too long |
| **Crooked/wavy bead** (p.37) | Steady both hands / rest hand on stable surface; consistent travel; shorter CTWD |
| **Coat of slag** (p.36) | Normal for flux-cored — slag shields the weld; chip + wire-brush after. Gas-shielded MIG doesn't produce protective slag. |

## Stick-weld diagnosis (pp.38–40)
Heat control: increase penetration → increase current, weld more slowly; reduce → decrease current, weld more quickly. [p.38]
| Symptom | Fix |
|---|---|
| Current too low (tall narrow bead) | Increase current |
| Current too high (flat burnt-looking) | Decrease current |
| Weld speed too fast | Weld slower |
| Weld speed too slow | Weld faster |
| **Arc length too short** | Increase electrode-to-work distance |
| **Arc length too long** | Decrease distance |
| Excess penetration/burn-through (p.39) | Reduce current; weld faster and steady |
| Inadequate penetration (p.39) | Arc on the leading edge of the puddle, correct angles; slow down so fill melts in; increase current; bevel thick pieces / gap / multiple passes; more fill material |
| Not adhering (p.39) | Technique (stringer placement, angles), more current, clean workpiece, more fill, close up gaps + bevel |
| Porosity (p.40) | Clean workpiece + electrode (oil/coatings/residues); consistent weld speed |
| Excessive spatter (p.40) | Clean workpiece and fill material |
| Crooked/wavy (p.40) | Two hands or rest a hand; steady speed |
| Burn-through (p.40) | Reduce current; faster steady speed; less fill |
| Slag coat (p.40) | Normal for stick — chip + brush after welding |

## Cleaning welds (p.34)
Flux-cored and stick welds carry slag: knock off with the **chipping hammer** (careful not to damage weld/base), then **wire brush**; shape with an angle grinder if needed. Keep ANSI goggles on — chips fly.
