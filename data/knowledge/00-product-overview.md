# Product Overview — Vulcan OmniPro 220 (Item 57812)

The Vulcan OmniPro 220 is a multiprocess welding system sold by Harbor Freight under the Vulcan brand. [cover, p.1]

- **Processes:** MIG (solid-core wire + shielding gas), Flux-Cored (gasless wire), DC TIG, and Stick. [p.7]
- **Dual-voltage input:** runs on 120VAC or 240VAC, 60 Hz, using the supplied dedicated power cord for each voltage. The cord plugs into the Power Input socket on the back and only fits one way. [p.7, p.16, p.25]
- **Synergic LCD control system:** pick a process on the LCD, set wire/rod diameter and material thickness, and the machine auto-sets wire feed speed / voltage / amperage ("Auto Weld Settings"). Manual override is available — a white mark on the settings line shows the recommended value for your wire and thickness. [p.20]
- Maximum open-circuit voltage (OCV): **86 VDC** for all processes. [p.7]
- Wire spool capacity up to 12 lb; wire speed range 50–500 IPM. [p.7]
- Aluminum can be MIG-welded **only with the optional Spool Gun** (sold separately) using aluminum wire and shielding gas. [p.7, p.17, p.18]
- TIG on this machine is **DC only** — mild steel, stainless, chrome moly. It cannot AC TIG weld aluminum/magnesium (the selection chart notes those need AC TIG). [p.7, selection chart]
- TIG torch and foot pedal are **sold separately**. [p.24]
- Tech support: 1-800-444-3353 / productsupport@harborfreight.com. 90-day limited warranty. [p.1, p.48]
