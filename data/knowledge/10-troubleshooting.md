# Troubleshooting Matrices (manual pp.42–44)

**IMPORTANT: shut off the welder, disconnect from power, and discharge the gun/electrode to ground before adjusting, cleaning, or repairing.** [pp.42, 44]

## MIG / Flux-Cored (pp.42–43)

### Wire feed motor runs but wire does not feed properly
1. Insufficient wire feed pressure → increase feed pressure properly (drive-tension procedure, p.17 step 27).
2. Incorrect feed roller size → flip roller to correct size (feed-roller procedure, p.12).
3. Damaged MIG gun, cable, or liner assembly → qualified technician inspect/replace.
4. Feed tensioner too tight → loosen so it applies only enough pressure to prevent continued spinning after trigger release.

### Wire creates a bird's nest during operation
1. Excess wire feed pressure → adjust (p.17 step 27).
2. Incorrect contact tip size → replace with proper tip for the wire.
3. Gun cable connector not fully inserted into the wire feed mechanism → insert properly (p.13 steps 13–14).
4. Damaged liner → technician repair/replace.

### Wire stops during welding
1. Gun cable severely bent → straighten.
2. Gun liner clogged or worn → check for obstruction, replace if necessary.
3. Liner too small for the wire → check liner size.
4. Wire tangled on the spool → check for cross-winding.
5. Wire not contacting feed rollers → check roller groove is correct for the diameter.
6. Feed roller not gripping, or crushing flux-cored wire → check the feed tensioner setting.

### Welding arc not stable
1. Wire not feeding properly → see first section.
2. Wrong contact tip / liner size or excessive wear → replace with proper size.
3. Incorrect wire feed speed → adjust WFS for a more stable arc.
4. Loose MIG gun cable or ground cable → tighten all connections.
5. Damaged gun / loose connection in gun → technician.
6. **Incorrect polarity → DCEP for MIG, DCEN for flux-cored self-shielded.**
7. Gas coverage insufficient or too high → set flow per settings chart; gun cable connector fully inserted with no O-rings exposed.
8. Poor workpiece connection → check ground clamp on clean bare metal and gun secured.

### Weak arc strength
1. Incorrect line voltage → check; licensed electrician if insufficient.
2. Improper cord gauge/length → **no extension cords**; only a supplied or identical power cord.
3. Not enough current → switch current setting to match metal thickness.

### Welder does not function when switched on
1. Tripped thermal protection → wait with power ON to cool (warning screen on LCD); reduce welding duration/frequency (duty cycle, p.19).
2. Circuit supplies insufficient voltage/amperage → verify circuit meets the spec table (p.7); check input voltage if a warning screen shows.
3. Faulty/improperly connected trigger → seat the gun connection; technician to check/replace.
4. Machine in low- or over-voltage protection → check input voltage is in range; if correct, **press the Reset Button on the back of the machine**.
5. Wrong mode → ensure the correct process is selected.

### LCD does not light when switched on
1. Unit not connected properly → verify outlet voltage and connection.
2. Outlet unpowered → check breaker/GFCI; fix cause before resetting.
3. Wrong plug rating → correct plug per specifications (p.7).
4. Breaker tripped from high input amperage → press the **Reset Button on the back**.
5. Twist-lock power cord not fully seated → secure the input power cord.

### Wire feeds but arc does not ignite
1. Improper ground connection → ground clamp on properly cleaned workpiece near the weld.
2. Improperly sized contact tip → verify/replace.
3. Excessively worn tip (hole deformed/enlarged) → replace.
4. Dirty contact tip → clean properly.

### Porosity in the weld metal
1. Gas bottle empty → check/replace.
2. Too little or too much shielding gas → check regulator flow.
3. Dirty workpiece → clean to bare metal.
4. Gun too far from work → check CTWD.
5. **Polarity incorrect → DCEP for MIG, DCEN for flux-cored.**
6. Dirty welding wire → clean wire, free of rust and residues.

## TIG / Stick (p.44)

### Welder does not function when switched on
1. Tripped thermal protection → reduce welding duration/frequency (duty cycle, p.29).
2. Faulty/improperly connected trigger → technician check/replace.
3. Ground clamp not attached to workpiece → attach.
4. Shielding gas not connected (TIG) → connect.

### LCD does not light
1. Connection/outlet → verify voltage at outlet and connection.
2. Breaker/GFCI tripped → determine and fix cause before resetting; verify the circuit supplies the required input amperage (p.7).

### Weak arc strength
1. Line voltage → electrician if insufficient.
2. Cord → no extension cords; supplied/identical power cord only.

### Welding arc not stable
1. Loose electrode or ground cable → tighten all connections.
2. Damaged electrode holder / loose connection in holder → technician.
3. Current setting → match the recommended setting on the chart.
4. Shielding gas low (TIG) → replace cylinder.

## Maintenance basics (p.41)
- **Before each use:** inspect general condition — loose hardware, misalignment/binding, damaged cord/cables, cracked parts.
- **Periodically:** qualified technician removes the rear panel and blows dust out with compressed air.
- **After every use:** store clean and dry.
- **MIG/Flux quality:** clean and inspect the contact tip and nozzle before each use — nozzle end flat and even (uneven/chipped/melted = replace); tip hole an even circle, not oblong (else replace); scrub with wire brush; tip cleaner for the tip bore.
